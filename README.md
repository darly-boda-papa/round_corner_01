# Neon Edge Live

휴대폰 디스플레이의 **라운드 코너 끝단을 따라 네온 선을 회전**시켜, 기구 베젤과 디스플레이 끝단 사이에 보이는 선의 두께가 **코너를 돌 때도 일관된지** 확인하는 모바일 웹 앱(PWA)입니다.

- 실행 형태: 폰 브라우저 / 홈 화면 설치 앱 (오프라인 동작)
- 배포: GitHub Pages (`https://<ID>.github.io/<저장소>/`)
- 외부 서버, 외부 라이브러리 없음. 설정은 브라우저 안(localStorage)에만 저장됩니다.
- 현재 버전: **v6**

---

## 1. 주요 기능

### 네온 표시
- 상태바, 카메라 홀, 내비게이션바 영역까지 포함해 **디스플레이 맨 끝**에 네온 링을 그립니다.
- 3겹 구성: 번짐(bloom) + 색 링 + 회전하는 흰 하이라이트
- 화면 꺼짐 방지(Wake Lock): 네온이 켜져 있는 동안 화면이 꺼지지 않습니다.

### 설정 (⚙ 버튼)
| 항목 | 범위 | 기본값 |
|---|---|---|
| Round Corner | 0 ~ 90 dp | 39 dp |
| 선 굵기 | 1 ~ 24 px | 3 px |
| 속도 | 0.5 ~ 8 초/바퀴 | 2.0 초 |
| 회전 방향 | 반시계 ↺ / 시계 ↻ | 시계 |
| 색상 팔레트 | 무지개 / 갤럭시 / 오로라 / 선셋 | 무지개 |

- 바꾼 설정은 자동으로 저장되고, 다시 열어도 유지됩니다 (저장 키 `neonLiveCfg2`).
- **↺ 최초 설정으로 초기화**: 위 기본값으로 되돌립니다.
- **전체화면 / 전체화면 해제** 버튼: 항상 보입니다.

### 전체화면
- **홈 화면 설치 앱**: 실행하는 즉시 전체화면입니다 (`manifest.json`의 `display: fullscreen`).
- **브라우저로 열기**: 가운데에 "화면을 탭하면 전체화면으로 시작합니다" 안내가 뜨고, 한 번 탭하면 전체화면이 됩니다.
  - 브라우저 정책상 터치 없이 전체화면으로 들어갈 수는 없습니다.
- 뒤로 가기 제스처 등으로 전체화면이 풀리면 다음 터치 때 다시 전체화면으로 들어갑니다.
- "전체화면 해제" 버튼으로 직접 나간 경우에는 자동으로 다시 들어가지 않습니다.

### 화면 UI 자동 숨김
- 하단 설정값 표시와 ⚙ 버튼은 **3초 동안 조작이 없으면 숨겨지고**, 화면을 탭하면 다시 나타납니다.
- 설정 패널이 열려 있는 동안에는 숨기지 않습니다. 패널 바깥을 탭하면 패널이 닫힙니다.

### 카메라 컷아웃 안내
- 전체화면인데 단말이 창 일부를 잘라내면(창 크기가 화면 크기보다 작으면) 화면 가운데에 설정 방법 안내가 자동으로 뜹니다.

### 진단 정보
- 설정 패널 아래의 **`v6 · 오프라인` 글자를 탭하면** 진단 줄이 보였다 숨겨졌다 합니다.
  ```
  창 360×840 / 화면 360×840 · fullscreen · API on
  ```
  - **창 / 화면**: 앱 창 크기와 디스플레이 크기 (dp). 두 값이 같으면 맨 끝까지 그려지고 있는 것입니다.
  - **fullscreen / standalone / browser**: 실행 방식
  - **API on/off**: 탭으로 들어간 전체화면 상태인지 여부

### 오프라인 앱 (PWA)
- 한 번 열면 서비스 워커가 파일을 저장해 두어서 인터넷 없이도 실행됩니다.
- 설정 패널에 `· 오프라인`이 보이면 저장이 끝난 것입니다.
- 📲 앱 설치 버튼: 브라우저가 설치할 수 있다고 알려 줄 때만 보입니다. 이미 설치했거나 앱 안에서 실행 중이면 보이지 않습니다.

## 2. 파일 구성

모든 파일은 저장소 **루트**에 둡니다 (폴더 없음, 약 110KB).

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `app.js` | 네온 애니메이션, 설정, 전체화면, 자동 숨김, PWA 등록 |
| `manifest.json` | 설치 정보 (`display: fullscreen`, 검은 배경) |
| `sw.js` | 서비스 워커 (앱 파일은 네트워크 우선, 오프라인이면 저장본 사용) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 (네온 둥근 사각형) |
| `README.md` | 이 문서 |

> `Neon Edge Live (standalone).html`은 원본(React 번들) 파일이라 업로드하지 않습니다.

## 3. 배포 (GitHub Pages)

1. 위 파일을 GitHub 저장소 루트에 업로드합니다 (모바일 브라우저 → Add file → Upload files).
2. Settings → Pages → Branch: **main / (root)** 로 지정합니다.
3. `https://<ID>.github.io/<저장소>/` 로 접속합니다.
4. 업로드한 뒤 설정 패널의 **버전 표시**로 새 버전이 반영됐는지 확인합니다. 옛 버전이 보이면 앱을 완전히 종료하고 다시 엽니다.

> 회사 PC에서 만든 PNG 아이콘은 사내 DRM으로 깨질 수 있으니, 업로드한 뒤 GitHub에서 이미지가 정상으로 보이는지 확인합니다.

### 설치
- **Chrome**: ⚙ → 📲 앱 설치, 또는 메뉴 → "홈 화면에 추가" / "앱 설치"
- **삼성 인터넷**: 메뉴 → "현재 페이지 추가" → "홈 화면"

## 4. 문제 해결

### 전체화면인데 화면 위쪽에 빈 띠가 남음 (카메라 홀 영역)
- **증상**: 진단 줄의 창 높이가 화면 높이보다 작습니다. 예: Galaxy Z Fold8 Ultra 커버 화면에서 `창 360×804 / 화면 360×840`
- **원인**: One UI의 앱별 카메라 컷아웃 설정이 앱 창의 카메라 줄을 잘라냅니다. 웹 코드로는 해결할 수 없습니다.
- **해결**: 설정 → 디스플레이 → **카메라 컷아웃**에서 **사용 중인 브라우저**(예: 삼성 인터넷)를 **"카메라 영역 보이기"** 로 바꿉니다.
  - 삼성 인터넷으로 설치한 웹 앱은 목록에 앱 이름이 아니라 "삼성 인터넷"으로 나옵니다.
- **다른 사용에 미치는 영향**: 일반 웹 서핑에는 영향이 없습니다. 브라우저 전체화면(동영상, 웹 게임 등)에서 가장자리 일부가 카메라 홀에 가려질 수 있습니다. 언제든 원래대로 되돌릴 수 있습니다.

### 가끔 3초쯤 뒤에 저절로 전체화면으로 돌아감
- 앱에는 이런 타이머가 없습니다. 3초 타이머는 하단 UI를 숨기는 데만 씁니다.
- 전체화면 중에 화면 가장자리를 쓸면 시스템 바가 잠깐 나타납니다. 안드로이드가 이 바를 약 3초 뒤 자동으로 다시 숨기는 것으로 보입니다 (OS 동작).

### 설치한 앱에서 "전체화면 해제"를 눌러도 변화가 없음
- 설치한 앱은 앱 자체가 전체화면으로 설치되어 있어서, 해제해도 다시 앱의 전체화면 상태로 돌아옵니다. 브라우저에서 열었을 때는 정상적으로 해제됩니다.

## 5. 버전 기록

| 버전 | 내용 |
|---|---|
| v1 | 원본(React 번들 단일 HTML)을 순수 html/js/css로 다시 만듦. 디스플레이 끝단까지 표시(`viewport-fit=cover`), PWA(오프라인, 설치), 화면 꺼짐 방지, 3초 UI 자동 숨김, 버전 표시, 초기값 표시 불일치 수정 |
| v2 | 브라우저 실행 시 "탭하면 전체화면으로 시작" 안내 추가. 직접 해제한 경우 자동으로 다시 들어가지 않게 함 |
| v3 | 실행 방식이 아니라 실제 화면을 덮는지로 전체화면을 판단. "전체화면 해제" 버튼, 최초 설정 초기화 버튼 추가 |
| v4 | 진단 줄(창/화면 크기, 실행 방식, API 상태) 추가 |
| v5 | 카메라 컷아웃 안내 자동 표시. 진단 줄은 기본 숨김, 버전 글자를 탭하면 표시 |
| v6 | 전체화면 버튼이 가끔 사라지던 문제 수정 (항상 표시). 앱 안에서는 설치 버튼을 띄우지 않음 |
